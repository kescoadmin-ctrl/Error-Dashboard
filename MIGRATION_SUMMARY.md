## Database Schema Required

### Supabase Setup Steps

1. **Create `users` table:**
   ```sql
   create table public.users (
     id uuid primary key references auth.users(id) on delete cascade,
     email text unique not null,
     role text not null check (role in ('administrator', 'coordinator')),
     settings jsonb default '{"topN": 10}'::jsonb,
     created_at timestamp with time zone default timezone('utc'::text, now()) not null,
     updated_at timestamp with time zone default timezone('utc'::text, now())
   );
   alter table public.users enable row level security;
   ```

2. **Create `snapshots` table:**
   ```sql
   create table public.snapshots (
     id bigint primary key generated by default as identity,
     user_id uuid not null references public.users(id) on delete cascade,
     date_str text not null,
     filename text,
     timestamp text,
     selected_columns text[],
     has_source boolean,
     flagged jsonb[] default '{}'::jsonb[],
     record_count integer default 0,
     flag_count integer default 0,
     created_at timestamp with time zone default timezone('utc'::text, now()),
     updated_at timestamp with time zone default timezone('utc'::text, now()),
     unique(user_id, date_str)
   );
   alter table public.snapshots enable row level security;
   ```

3. **Create `snapshots` storage bucket** (private, not public)

4. **Full SQL setup instructions available in `SETUP.md`**

## Key Changes in Code

### Authentication
**Before:**
```javascript
import { signInWithEmailAndPassword } from 'firebase/auth'
await signInWithEmailAndPassword(auth, email, password)
```

**After:**
```javascript
import { supabase } from './supabase'
await supabase.auth.signInWithPassword({ email, password })
```

### Database Queries
**Before:**
```javascript
const q = query(collection(db, 'users', userId, 'snapshots'))
const snapshot = await getDocs(q)
```

**After:**
```javascript
const { data, error } = await supabase
  .from('snapshots')
  .select('*')
  .eq('user_id', userId)
```

### Real-Time Subscriptions
**Before:**
```javascript
onSnapshot(query(...), (snapshot) => { ... })
```

**After:**
```javascript
supabase.from('snapshots').on('*', (payload) => {
  if (payload.new.user_id === userId) { ... }
}).subscribe()
```

### File Storage
**Before:**
```javascript
await uploadBytes(storageRef, blob)
```

**After:**
```javascript
await supabase.storage
  .from('snapshots')
  .upload(fileName, blob)
```
